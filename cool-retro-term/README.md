# 📺 Cool-Retro-Term Monochrome Profile

This directory contains the custom **Monochrome** profile for [cool-retro-term](https://github.com/Swordfish90/cool-retro-term).

### Profile Specifications
- **Theme:** Pure Monochrome (White text `#ffffff` on Black `#000000`)
- **Font:** JetBrainsMono Nerd Font
- **Window Opacity:** 0.8 (Translucent background)
- **Effects:** High-resolution native rasterization (1), subtle CRT flicker (0.05), balanced bloom (0.15), glowing scanlines (0.05), blinking cursor.

### How to Import
1. Launch `cool-retro-term`.
2. Right click inside the terminal window to open the context menu.
3. Select **Settings** -> **Profiles** tab.
4. Click **Import Profile** and select `cool-retro-term-monochrome.json`.
5. Select the imported profile "Monochrome" and click **Load**.
